## 基本ルール
英略語・カタカナ用語は初出だけでなく **毎回** 日本語注釈を併記する。

## 形式
- 略語: `PoC (試作検証)` ← 略語 + (日本語)
- 用語: `LLM (大規模言語モデル)`
- 三層: `MCP (Model Context Protocol)` ← 完全展開 + (省略可なら日本語)
- カタカナ: `ハーネス (実行基盤)` ← カタカナ + (具体的役割)

## 適用範囲
- ユーザーへの応答 (text)
- video-notes / memory / docs などのドキュメント
- コミットメッセージ
- PR 説明

## 除外
- コードコメント（英語のままでOK）
- ファイル名・ディレクトリ名
- 既に文脈で明確な場面（連投2回目以降は省略可）

## Why
- 読み手が英略語に不慣れな場合がある (フィードバックより)
- 過去メッセージで「PoC とは？」「これ何？」が頻発したため
- 注釈があれば後で読み返す時も即わかる

## How to apply
- 1回目は完全形 + 日本語
- 2回目以降は短縮形 + 日本語 (例: PoC (試作))
- 既に同じセッションで何度も出てる場合は注釈省略可
