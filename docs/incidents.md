## 補足

- 「恒久対応済み（運用ルール化）」は CLAUDE.md / rules/ への記述で担保しているもので、コードやコマンドの状態ゲート（hook）による 100% 強制ではない。決済・削除・本番送信のような「絶対に起きてはいけない」操作は hook 化し、それ以外の再発防止は運用ルールで対応する、という方針に基づく取捨選択である。
- 本ハーネスの `hooks/pretooluse-guard.py`（破壊的コマンド・SQL破壊操作・シークレット直書きのブロック）と `hooks/pretooluse-heredoc-gate.py` は、この表の中で hook 化まで到達した唯一の2件の直接的な帰結である。他の項目は将来 hook 化を検討する候補として残す。
